# Secure CI/CD Pipeline & AppSec Research

Reusable DevSecOps workflow templates, custom security check scripts, and API security research notes by **Chetan Biranje**.

## Contents

- `.github/workflows/security-gate.yml`: Reusable GitHub Actions workflow for pull request security gating.
- `rules/semgrep-custom-rules.yml`: Custom Semgrep rules for detecting insecure cryptographic defaults and missing authorization checks.
- `docs/IDOR_Testing_Methodology.md`: Complete guide and testing checklist for Insecure Direct Object References (IDOR).
